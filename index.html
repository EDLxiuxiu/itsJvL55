这门简单语言如何书写

类型关键字为 int、real、char、bool，区分大小写。名字可含英文字母、数字和下划线，不能以数字开头，也不能使用关键字。

const int LIMIT = 100;
const char NEWLINE = '\n';
real price = 12.5;
bool finished;
*
  • 常量必须有初值；变量初值可省略，省略时显示“未初始化”。
  • 整数支持十进制、0x/0X 十六进制；int 限定为 32 位有符号整数。
  • 实数必须有小数点，可带指数，例如 12.、0.5、1.2e+3。real 也可接收整数字面量。
  • char 用英文单引号包围一个 Unicode 字符，支持 \n、\r、\t、\0、\'、\"、\\。
  • bool 初值只能为 true 或 false。数值可带一个正负号。
  • 支持 // 单行注释和 /* */ 多行注释，不支持注释嵌套。
  • * 必须单独占一行；之后只能有空白或合法注释。
  • 不支持表达式、名字引用、多变量声明、数组、函数或嵌套作用域。
  • 错误声明不登记、不占空间；尽量在分号或下一行声明开头恢复分析。

这是自行定义的教学语言，并非完整 C 语言。地址是模拟偏移量，char 的 4 字节是本系统为单个 Unicode 码点规定的教学存储模型。
