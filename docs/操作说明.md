# 操作说明

聊天中按步骤进行即可，本文用于需要时查阅。先完成当前一步，再进行下一步。

## 第一步 打开页面

1. 打开桌面的“编译原理实验三综合实验”文件夹。
2. 进入 declaration-analyzer 文件夹。
3. 双击 index.html。若打开成代码或编辑器，右键 index.html，选择“打开方式”，再选择浏览器。
4. 页面标题应为“常量与变量声明分析”。
5. 默认示例自动分析，右侧应为：常量 4、变量 5、模拟空间 21、错误 0，状态为“分析通过”。

如果只显示没有样式的文字，确认 css 文件夹仍在 index.html 旁边。如果按钮无反应，确认 js 文件夹和其中三个文件都在，且没有只复制 index.html。若页面与说明不同，先保留画面，回到聊天中描述现象。

## 第二步 运行内置示例

每次选择一个示例，再点击“载入”。页面会自动分析。

| 示例 | 常量 | 变量 | 字节 | 错误 |
| --- | --- | --- | --- | --- |
| 综合正确示例 | 4 | 5 | 21 | 0 |
| 四类常量 | 4 | 0 | 0 | 0 |
| 变量与地址分配 | 0 | 4 | 17 | 0 |
| 重定义检查 | 1 | 2 | 8 | 2 |
| 类型与范围错误 | 0 | 1 | 8 | 4 |
| 格式错误与恢复 | 0 | 3 | 9 | 3 |

点击“符号表”“常量表”“变量表”“Token”“错误信息”“处理过程”切换查看。每次修改输入后，需要重新点击“开始分析”；页面会提示旧结果尚未更新。

## 第三步 自己修改一条声明

1. 载入“综合正确示例”。
2. 把 int count = 0; 改为 int count = 2.5;。
3. 点击“开始分析”。
4. 查看“错误信息”，应出现类型不匹配。
5. 查看变量表，count 不登记，后续变量从未被占用的地址继续分配。
6. 再把该行改回去并分析。

## 第四步 保存结果

- “保存输入 .txt”：保存编辑区文字。
- “导出 JSON”：保存当前已分析输入的 Token、符号、诊断和处理记录。
- “导出分析摘要 .md”：保存当前实际分析汇总和结果表，可用于整理报告。
- 输入修改后结果导出按钮暂时禁用，重新分析后恢复。
- 下载位置由浏览器设置决定。
- “导入文本”读取 UTF-8 文件，可使用 examples 文件夹中的六份示例。

## 第五步 采集报告证据

建议保存综合正确示例、四类常量表、变量地址表、Token 表、重定义错误、类型错误、格式错误恢复等画面。报告中的核心代码、表格尽量使用可编辑文本；截图只用于展示实际界面。
