## 实验内容及原理

按 docs/LANGUAGE.md 说明自定义语言的语法、字面量形式、类型检查、终止标记与存储规则。明确这是单作用域教学语言，地址为模拟偏移量，char 规定为 4 字节。

可按以下流程绘图：源文本 -> 词法扫描 -> Token -> 声明分析 -> 类型与重定义检查 -> 符号表/地址分配 -> 结果和诊断。

## 总结与自评

可如实总结的功能：四类常量与变量、符号表、模拟地址、三类错误、恢复、导入导出。

可如实陈述的特点：分析核心与界面分离；失败声明原子提交；错误后继续分析；无需安装运行环境。

缺陷应包括：仅支持固定类型、单作用域与字面量初值；无表达式、数组和函数；恢复策略有限；浮点数采用双精度表示。
