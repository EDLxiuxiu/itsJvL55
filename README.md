# 常量与变量声明分析系统

编译原理实验三综合实验，对应参考选题 4：常量说明与基本数据类型说明分析。

使用 HTML、CSS、原生 JavaScript。在本地打开 `index.html` 即可使用，无需安装运行环境、构建工具、后端、数据库或联网。完整源码均在本目录内。

## 打开方法

1. 保持整个文件夹结构不变。
2. 用现代浏览器打开 `index.html`（可双击，也可右键选择浏览器）。
3. 页面自动载入并分析综合正确示例。
4. 预期结果：4 个常量、5 个变量、21 字节、0 个错误。

## 主要功能

- 识别 int、real、char、bool 四种类型，支持常量和变量声明。
- 输出带种别码、原文、值、行号、列号的 Token 序列。
- 识别十进制/十六进制整数、带小数点的实数、科学计数实数、Unicode 单字符及转义、布尔字面量。
- 检查声明格式、常量初值、类型兼容、整数范围、名字重定义。
- 建立全局符号表，并为有效变量分配模拟存储地址。
- 输出词法、语法和语义诊断，使用分号/后续声明开头恢复分析。
- 提供六组内置示例，支持 UTF-8 文本导入、保存输入、导出 JSON 和 Markdown 分析摘要。
- 修改输入后将结果标记为旧结果，重新分析后才允许导出结果。

## 输入示例

```text
const int LIMIT = 100;
const real RATE = 1.25e+2;
const char GRADE = 'A';
const bool READY = true;
int count = 0;
real price = 19.5;
char level = '优';
bool enabled;
*
```

每条声明以英文分号结尾；`*` 单独占一行结束输入。支持 `//` 与 `/* */` 注释。

## 存储模型与边界

int 4 字节、real 8 字节、char 4 字节、bool 1 字节。变量从地址 0 起连续分配，不考虑对齐。char 的 4 字节是教学语言对单个 Unicode 码点的规定，不是 C 语言 char 大小。常量仅登记值，不占变量空间。错误声明不登记、不占空间。

仅支持单一全局作用域、每条声明一个名字、字面量初值及数值正负号。不支持算术表达式、名字引用、多变量声明、数组、函数或真实内存分配。这是自行定义的教学语言，不是完整 C 语言。

## 可选的开发验证

使用网页无需 Node.js。若维护代码且本机已有 Node.js，可在本目录执行：

```text
node tests/analyzer.test.js
```

加入 `--report` 可刷新 `docs/TEST_RESULTS.md`。自动化测试主要覆盖分析核心；界面的导入、下载、弹窗和不同窗口大小仍需浏览器验证。
